# Sarf Image Assets

This directory should contain images of Moroccan banknotes and coins.

## Required Files

Please add the following image files (PNG format):

- `200.png` - 200 MAD banknote
- `100.png` - 100 MAD banknote
- `50.png` - 50 MAD banknote
- `20.png` - 20 MAD banknote
- `10.png` - 10 MAD coin
- `5.png` - 5 MAD coin
- `2.png` - 2 MAD coin
- `1.png` - 1 MAD coin

## Image Specifications

- Format: PNG (recommended) or other Android-supported formats
- Recommended size: 64x64 dp or larger for good quality display
- The app will scale images as needed

## Note

If images are missing, the app will still function but won't display images for the denominations.
The app will show the denomination text (e.g., "200 MAD × 1") without the image.
